# 🧮 Servlet Calculator Project

A simple web-based calculator built using Java Servlets and deployed on Apache Tomcat.  
This project performs basic arithmetic operations like addition.

---

## 🚀 Features

- Takes user input from a web form
- Performs addition of two numbers
- Displays result in browser using Servlet response
- Built using Java Servlet (Jakarta EE)

---

## 🛠️ Technologies Used

- Java
- HTML
- Jakarta Servlet API
- Apache Tomcat Server
- Eclipse IDE
